#  Sales & Demand Forecasting Project

## Objective
Predict future sales using historical data.

## Models Used
- Linear Regression
- Random Forest (Final Model)

##  Results
- Achieved ~0.9 R² Score
- Improved accuracy using Random Forest

##  Key Insights
- Sales fluctuate over time
- Holidays significantly increase sales
- Fuel price has minimal impact

##  Tools & Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn

##  Conclusion
The model can effectively predict future sales, helping businesses in planning inventory and demand.
